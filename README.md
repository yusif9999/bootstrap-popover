# Lumina Space - Coworking Space Landing Page

A modern, fully responsive landing page for a next-generation coworking space and cafe. This project was built to demonstrate the practical, real-world application of advanced Bootstrap 5 components, including interactive elements like Popovers, Tooltips, and Tab Panels, entirely without writing custom CSS.

## 💡 About The Project

Lumina Space provides a digital storefront for a modern workspace tailored for freelancers and students. The layout is strictly constructed using Bootstrap's Grid and Flexbox utilities, ensuring a seamless experience across mobile, tablet, and desktop devices. 

Instead of relying on external JavaScript libraries for interactivity, this project leverages Bootstrap's native JS bundle to bring the UI to life with dynamic components.

### Key Features & Components Demonstrated:
*   **Interactive Popovers:** Implemented in the FAQ section to display cancellation policies and working hours without navigating away from the page.
*   **Dynamic Tabs:** Used in the "Services" section to seamlessly switch between "Cafe & Break" and "Quiet Zone" content areas.
*   **Tooltips:** Added to specific icons and buttons to provide users with extra context (e.g., internet speed, coffee bean origins).
*   **Progress Bars:** A styled, animated progress bar simulating real-time workspace occupancy.
*   **Responsive Collapse (Menu):** A manually built, fully responsive navigation menu using Flexbox and Bootstrap's Collapse plugin (without relying on the standard Navbar component).
*   **CSS Utilities:** Extensive use of Bootstrap spacing (margin/padding), display properties, opacity, and shadow utilities for a polished look.
